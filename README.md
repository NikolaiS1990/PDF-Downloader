# 🛠️ Installation
1. Install uv
unix based OS: `curl -LsSf https://astral.sh/uv/install.sh | sh`.
Windows: `powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex`.

2. Clone the github repository from: `https://github.com/NikolaiS1990/PDF-Downloader`

3. run `uv sync --no-dev` to download the packages.

If you are a developler, then run `uv sync`

4. Activate the environment:
Linux, MacOS, BSD:
```bash
source .venv/bin/activate
```

Windows:
```PS
.venv\Scripts\activate
```

# How to run the program
```bash
uv run pdf-downloader \
    --output_path /path/to/output \
    --download_path /path/to/download \
    --excel_gri_file_path /path/to/gri.xlsx \
    --download_link_column COLUMN \
    --download_link_column_alternative COLUMN
```

### 🧪 Run unit tests (for developers)
To run all unit tests, run this line
```bash
uv run pytest tests/ -v
```

How to run unit test on a specific file:
```bash
uv run pytest <filepath> -v
```

See what test coverage percentage you have:
```bash
uv run pytest --cov=src/pdf_downloader --cov-report=term-missing
```

### 🧹 Linting
#### Let ruff catch syntax errors
```bash
uv run ruff check --fix <path to file>
```

#### Run ruff formatter
```bash
uv run ruff format <path to file>
```
